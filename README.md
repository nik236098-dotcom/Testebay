# Монитор новых лотов lzt.market и tronaccs.market → Telegram

Бот раз в минуту (настраивается) проверяет лоты по вашим фильтрам на двух
маркетах и присылает каждый новый лот в Telegram: название, цена, страна,
контакты, спамблок, ссылка и кнопка «Купить».

Бот многопользовательский: у каждого пользователя свои токены API, свой
фильтр, свои настройки и свои лоты. Доступ выдаёт владелец одноразовым кодом.

## Что нужно

1. **Telegram-бот.** У @BotFather выполните `/newbot`, токен положите в `TG_BOT_TOKEN`.
2. **Ваш Telegram ID** в `TG_USER_ID` (узнать: написать боту `/id`). Это владелец.
3. **Токен lzt.market**: https://lolz.live/account/api, область `market`, в `LZT_TOKEN`.
   Доступ к API маркета платный.
4. **Токен tronaccs** (необязательно): на сайте нажмите на ник → «API TronAccs»
   → создать токен, в `TRON_TOKEN`.

Токены из `.env` попадают в профиль владельца. Другие пользователи вводят
свои токены прямо в боте при регистрации.

## Запуск

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # заполнить токены
python monitor.py         # запустить, затем написать боту /start
```

При первом запуске бот запоминает уже существующие лоты и молчит. Дальше
присылает только новые.

## Как дать доступ другу

1. Владелец пишет боту `/invite yazaurkainu` (любой код без пробелов, или
   `/invite` без аргумента, тогда код сгенерируется).
2. Друг пишет боту `/pin yazaurkainu`. Код одноразовый, после этого сгорает.
3. Бот просит токен lzt.market, потом токен tronaccs (любой можно пропустить
   командой `/skip`). Токены проверяются запросом к маркету, сообщения с ними
   бот удаляет из чата.
4. Открывается меню `/settings`: страна, контакты, спамблок → «Сохранить условия».

Владелец видит список пользователей `/users` и может удалить `/kick <id>`.

## Главное меню и экраны

`/start` и `/menu` открывают главное меню с кнопками:

- **Балансы площадок** — отдельные актуальные балансы lzt.market и tronaccs.
- **Настройки поиска** — страна по-русски, минимум контактов, спамблок и цена.
- **Статус** — применённые условия каждой площадки, результат и время проверки.
- **Проверить сейчас** — свежая проверка и ссылки на последние подходящие аккаунты.

Обычный текст, непонятный символ, неизвестная команда, `/start` и `/menu`
присылают новое главное меню внизу чата. Кнопки редактируют то сообщение,
на котором нажаты. Команды экранов (`/settings`, `/status`, `/balance`)
обновляют последнее меню. Его номер сохраняется в профиле после перезапуска.
Если прежнее сообщение удалено и Telegram не позволяет его редактировать,
бот создаёт новое. Сетевой сбой редактирования
не создаёт дубликат. Загрузка балансов идёт в фоне; можно сразу перейти на
другой экран, и поздний ответ его не заменит.

В настройках нажмите **«Сохранить условия»**. До сохранения статус показывает
действующие условия, а не черновик. **«Любая цена»** снимает оба ограничения.
При ошибке проверки статус пишет, что количество неизвестно, вместо ложного
нуля. Старые аккаунты учитываются в результатах; уведомления приходят о новых.

`/balance` (или `/balances`) открывает тот же экран балансов. `/help` сохраняет
список расширенных команд.

## Команды бота

- `/settings` — меню с кнопками: страна, минимум контактов, спамблок, цена
  (от, до или любая). Фильтр применяется к обоим сайтам, галочками можно
  оставить один.
- `/check` — проверить прямо сейчас: сколько лотов и три последних с кнопками.
  Один быстрый запрос без повторов; если сайт не ответил, ошибка придёт сразу.
  Долгие команды (`/check`, `/status`, дампы, `/tronid`) и покупка по кнопке выполняются в фоне и
  не мешают остальным командам и кнопкам.
- `/status` — фильтры, число проверок, балансы, последняя ошибка.
- `/autobuy` — автопокупка новых лотов по своим условиям. Площадки отмечаются
  галочками, можно включить lzt.market и tronaccs одновременно; память лотов и
  тихая первая проверка ведутся по каждой площадке отдельно.
- Если сайт не отвечал (техработы, 503) две проверки подряд и больше, бот молчит,
  а когда сайт снова ответит, присылает одно сообщение «снова работает».
- `/token` — показать токены (замаскированно), `/token lzt` или `/token tron` — сменить.
- `/filter <ссылка>` — фильтр lzt.market ссылкой с сайта, для тонкой настройки.
- `/tron on|off`, `/tronfilter country=UZ contacts>=100 spam=no price<=500` —
  tronaccs вручную. Условия: `=`, `!=`, `>`, `<`, `>=`, `<=`, `~` (содержит).
- `/tronid UZ` — узнать ID страны на tronaccs (или вписать: `/tronid UZ 443`).
  Обычно не нужно: справочник стран подгружается сам.
- `/lztdump`, `/trondump` — показать лот в сыром виде, как отдаёт сайт.
- `/stop` — отписать чат, `/start` — подписать (можно добавить бота в группу).
- `/id` — Telegram ID. Владелец: `/invite`, `/users`, `/kick`.

## Кнопка «Купить»

Под каждым лотом кнопки «Купить за N ₽» и «Открыть на сайте». Покупка идёт
токеном того пользователя, который нажал: lzt через `POST /{item_id}/fast-buy`
с ценой из сообщения (если цена изменилась или лот продан, маркет откажет),
tronaccs через `POST /items/{id}/purchase`. Деньги списываются с баланса на
маркете, данные аккаунта на странице лота или в «Мои покупки».
`BUY_CONFIRM=1` включает шаг подтверждения.

После успешной покупки бот выгружает **только файл сессии** `<id>.session`,
без JSON и лишнего (`SESSION_ONLY=1`, включено по умолчанию). Он получается:

- напрямую, если маркет отдаёт готовый файл сессии (SQLite в base64 или
  ссылкой на `.session`);
- собирается из строковой сессии Telethon прямо в боте, без внешних библиотек.

Если из ответа маркета `.session` собрать не удалось, бот пришлёт полный
ответ в JSON и попросит прислать структуру ответа. Поставьте `SESSION_ONLY=0`,
чтобы получать и tdata, и сводку (телефон, dc_id, authkey, 2FA), и JSON.
Выгрузку целиком отключает `SEND_SESSION_FILES=0`.

### Автозагрузка сессии во внешнюю панель

Купленный `.session` бот может сам загружать в вашу панель (например
evangelion). Настройка в боте командой `/panel`:

- `/panel url <адрес>` — куда слать файл;
- `/panel token <ключ>` — токен доступа панели (уходит и заголовком, и полем);
- `/panel field <имя>` — имя поля с файлом в запросе (по умолчанию `file`);
- `/panel off` — выключить.

Точный адрес и имя поля берутся из самой панели: F12 → Network, загрузите
сессию вручную, правой кнопкой по запросу → Copy → Copy as cURL. По этому
запросу можно точно настроить `url` и `field`. У каждого пользователя своя
панель. Значения по умолчанию для владельца: `PANEL_URL`, `PANEL_TOKEN`,
`PANEL_FIELD` в `.env`.

Встроенный автобай маркетов срабатывает раньше любого внешнего бота, поэтому
кнопка нужна для ручной покупки, а не для гонки.

## Что известно про API

- lzt.market: `https://prod-api.lzt.market`, `Authorization: Bearer`,
  `GET /telegram` с параметрами сайта (`country[]`, `min_contacts`, `spam`,
  `order_by`, `page`), лимит 120 запросов в минуту.
  Спамблок в лоте: -1 нет, 1 есть, 0 не проверялся.
- tronaccs: `https://system-api.tronaccs.market` (документация
  https://tronaccs-market.readme.io), `GET /items?category=telegram` с
  фильтрами `priceFrom/To`, `contactsFrom/To`, `spamblock`, `premium`, `two_fa`
  и др., не чаще одного запроса в секунду. Страна в API принимает ID, справочник
  берётся с `api.tronaccs.market/countries`.

## Постоянная работа

- **systemd:** пример юнита в `lzt-monitor.service`.
- **Docker:** `docker compose up -d --build` (состояние хранится в `./data`).

## Файлы

- `monitor.py` — бот и монитор (`--once` одна проверка, `--test` тестовое
  сообщение, `--dump` сырой ответ lzt).
- `tron_source.py` — клиент API tronaccs и разбор фильтра.
- `web_source.py` — разбор HTML-страницы lzt для режима без API (`SOURCE=web`).
- `state.json` — профили пользователей, коды доступа, отправленные лоты.


## Проверка интерфейса без обращений к площадкам

```bash
python -m unittest -q test_bot_text.py test_bot_menu.py
```

Новые модули `bot_text.py` и `bot_menu.py` используют отложенные аннотации
для совместимости с Python 3.8. Docker-образ включает оба модуля.
