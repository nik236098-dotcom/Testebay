# AMART — магазин для собственного сервера

Полная витрина и админпанель: товары, категории, фотографии, баннер, отзывы, контакты, документы, корзина, заказы и уведомления в Telegram. Оплата согласуется с продавцом; банковской платёжки нет.

Это самостоятельная серверная версия. Для работы не нужны ChatGPT, Sites, D1 или R2. Используются Node.js 24, Next.js, SQLite и папка с фотографиями. Вход владельца — по паролю.

## Быстрая установка

Для чистого VPS с Ubuntu 24.04 / Debian 12+, от 2 ГБ RAM. На маленьком сервере для сборки может потребоваться swap. Нужны свободные порты 80 и 443. В DNS домена заранее укажите A-запись на IP сервера.

Войдите на сервер по SSH и выполните:

```bash
git clone --branch amart-store-server --single-branch https://github.com/nik236098-dotcom/Testebay.git amart-site && cd amart-site/amart-store && sudo bash deploy/install.sh
```

Если `git` ещё не установлен: `sudo apt-get update && sudo apt-get install -y git`.

Установщик спросит домен, установит Docker при необходимости, создаст случайный пароль, соберёт и запустит магазин. HTTPS для домена выдаёт Caddy автоматически. Пароль выводится в конце и хранится в локальном `.env`. Админпанель: `https://ВАШ-ДОМЕН/admin`.

Для временной проверки по IP можно ввести `http://IP-СЕРВЕРА`. Для постоянной работы и входа в админку используйте домен с HTTPS.

## Что находится в репозитории

- Дизайн сайта, все встроенные изображения и шесть готовых изображений отзывов, присланных владельцем.
- Начальный каталог, актуальные контактные данные Алии и редактируемые тексты.
- Локальная база создаётся при первом запуске; миграции применяются автоматически.
- Изменения сохраняются в Docker-томе `amart-store_shop_data`, вне кода и контейнера.

Это исходники с начальным наполнением. Заказы, загруженные через админку фотографии, секреты и последующие изменения базы опубликованного сайта автоматически сюда не копируются. Рабочий токен Telegram нужно заново указать в админпанели сервера. Не публикуйте `.env`, базу и резервные копии в GitHub.

## Управление сервером

Команды выполняются из папки `amart-site/amart-store`.

```bash
# Обновить код, предварительно сохранив резервную копию
bash deploy/update.sh

# Сделать резервную копию базы, фото и настроек
bash deploy/backup.sh

# Посмотреть состояние и последние сообщения сервера
docker compose ps
docker compose logs --tail=100 app

# Перезапустить
docker compose restart
```

Резервные копии находятся в `backups/`. Храните отдельную копию вне VPS. Не выполняйте `docker compose down -v`: ключ `-v` удаляет данные магазина.

Чтобы поменять домен, измените `SITE_ADDRESS` и `PUBLIC_ORIGIN` в `.env`, затем выполните `docker compose up -d --force-recreate`. `PUBLIC_ORIGIN` должен быть точным адресом с `https://` без завершающего `/`.

## Локальная разработка

Node.js 24 и pnpm 11.25.0. Скопируйте `.env.example` в `.env`, задайте пароль не короче 12 символов, `PUBLIC_ORIGIN=http://localhost:3000` и случайный `TELEGRAM_CONFIG_KEY` из 64 шестнадцатеричных символов.

```bash
corepack enable
corepack prepare pnpm@11.25.0 --activate
pnpm install --frozen-lockfile
pnpm dev
```

Проверка: `pnpm build && pnpm test`. Тест запускает настоящий Node-сервер с отдельной временной базой, проверяет доступ, товары, фото, баннер, отзывы, документы, заказы и сохранение после перезапуска. Реальные сообщения в Telegram не отправляются.

Контейнер Docker и получение HTTPS требуют сервера с Docker и доступного домена. Локально проверены production-сборка Next.js и серверные операции; Docker здесь не запускался.

Документация платформ: [Next.js self-hosting](https://nextjs.org/docs/app/guides/self-hosting), [Node.js SQLite](https://nodejs.org/docs/latest-v24.x/api/sqlite.html), [Docker Engine](https://docs.docker.com/engine/install/), [Caddy automatic HTTPS](https://caddyserver.com/docs/automatic-https).
