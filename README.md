# Монитор новых лотов lzt.market → Telegram

Скрипт раз в минуту (настраивается) проверяет лоты на lzt.market по вашим фильтрам
и присылает каждый новый лот в Telegram: название, цена, страна, контакты, спамблок,
ссылка на лот.

По умолчанию следит за
`https://lzt.market/telegram/?country[]=UZ&min_contacts=100&spam=no`.

Два источника данных, выбирается переменной `SOURCE`:

- `web` (по умолчанию, бесплатно) — монитор загружает обычную страницу
  каталога и вытаскивает лоты из HTML по ссылкам вида `lzt.market/<id>/`.
  Если сайт отдаёт проверку DDoS-Guard, помогают cookies из вашего браузера
  (`LZT_COOKIES`) или загрузка через настоящий Chromium (`USE_BROWSER=1`).
- `api` — официальный API Lolzteam Market (`prod-api.lzt.market`). Доступ
  к API платный, нужен `LZT_TOKEN`. Зато отдаёт структурированные поля лота.

## Что нужно

1. **Telegram-бот.** У @BotFather выполните `/newbot`, токен положите в `TG_BOT_TOKEN`.
2. **Ваш Telegram ID** в `TG_USER_ID`, чтобы бот отвечал только вам. Узнать его
   можно, написав боту `/id` после запуска, или у @userinfobot. Если оставить
   пустым, подписаться сможет любой, кто напишет боту `/start`.
3. **Только для `SOURCE=api`:** токен на https://lolz.team/account/api
   с областью `market` в `LZT_TOKEN`.

Никакой chat_id искать не нужно: после запуска монитора напишите боту `/start`,
и он начнёт присылать лоты в этот чат.

## Команды бота

- `/start` — подписаться на новые лоты
- `/stop` — отписаться
- `/status` — фильтр, источник, число подписчиков и запомненных лотов
- `/filter <ссылка>` — сменить фильтр на лету: откройте на lzt.market нужный
  раздел с фильтрами, скопируйте адрес из браузера и пришлите боту, например
  `/filter https://lzt.market/telegram/?country[]=KZ&min_contacts=50&spam=no`.
  Текущие лоты по новому фильтру бот запомнит молча и дальше будет присылать
  только новые. Фильтр сохраняется в `state.json` и имеет приоритет над `.env`.
- `/filter` — показать текущий фильтр
- `/check` — проверить прямо сейчас: сколько лотов по фильтру и три последних
- `/id` — показать ваш Telegram ID и id чата

## Кнопка «Купить»

Под каждым лотом две кнопки: **Купить за N ₽** и **Открыть на сайте**.
После нажатия «Купить» появляются «Подтвердить» и «Отмена», чтобы случайное
касание не списало деньги. Подтверждение вызывает `POST /{item_id}/fast-buy`
с той ценой, что была в сообщении: если продавец поднял цену или лот уже
продан, маркет откажет и деньги не спишутся. Деньги берутся с баланса
аккаунта Lolzteam. Данные купленного аккаунта смотрите на странице лота.

Покупка работает только в режиме `SOURCE=api` и только для пользователей из
`TG_USER_ID`. Учтите: встроенный автобай Lolzteam срабатывает раньше любого
внешнего бота, поэтому кнопка нужна для ручной покупки, а не для гонки.

Бот молчит, пока на маркете не появится новый лот по фильтру. При запуске он
присылает подписчикам «Монитор запущен» (отключается `NOTIFY_ON_STARTUP=0`),
а `/check` показывает, что он видит прямо сейчас.

Бот можно добавить в группу и написать `/start` там, тогда лоты будут
приходить в группу. Пользователям не из `TG_USER_ID` бот отвечает отказом.

## Запуск

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # заполнить токены
python monitor.py         # запустить мониторинг, затем написать боту /start
```

Проверить, что бот пишет всем подписанным чатам: `python monitor.py --test`.

Сначала выполните `python monitor.py --dump`: он покажет, какие лоты монитор
видит на странице. Если список пустой или вместо лотов ошибка про проверку
сайта, см. раздел «Если сайт блокирует запросы».

При первом запуске скрипт запоминает уже существующие лоты и молчит.
Дальше присылает только новые. Если хотите получить и текущие лоты,
поставьте `NOTIFY_ON_FIRST_RUN=1` перед первым запуском.

## Изменить фильтры

Скопируйте часть ссылки после `?` в `LZT_QUERY`, а категорию (часть пути) в `LZT_CATEGORY`:

```
https://lzt.market/telegram/?country[]=UZ&min_contacts=100&spam=no&pmax=500
                   ^^^^^^^^   ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
                   LZT_CATEGORY                LZT_QUERY
```

Параметр `order_by` из ссылки игнорируется: для поиска новых лотов монитор
всегда сортирует по дате публикации. Цена приходит в каждом сообщении, а
ограничить её можно параметром `pmax=` (максимум) и `pmin=` (минимум).

## Если сайт блокирует запросы (режим `web`)

lzt.market стоит за DDoS-Guard. Обычно после первой проверки в браузере
выдаются cookies, с которыми простые запросы проходят.

1. Откройте в браузере страницу с вашим фильтром, дождитесь загрузки лотов.
2. DevTools (F12) → Network → кликните любой запрос к lzt.market →
   Request Headers → скопируйте значение `Cookie` целиком.
3. Вставьте в `.env`: `LZT_COOKIES=...` и снова запустите `python monitor.py --dump`.

Если и это не помогает, поставьте `USE_BROWSER=1`: страница будет грузиться
через настоящий Chromium.

```bash
pip install playwright && playwright install chromium
```

Cookies живут ограниченное время. Если лоты перестали приходить, а в логах
ошибка про проверку сайта, обновите `LZT_COOKIES`.

## Постоянная работа

- **systemd:** пример юнита в `lzt-monitor.service`.
- **Docker:** `docker compose up -d --build` (состояние хранится в `./data`).

## Что известно про API

Сверено с документацией https://lzt-market.readme.io/reference/information и
официальными клиентами Lolzteam:

- Базовый адрес `https://prod-api.lzt.market`, авторизация заголовком
  `Authorization: Bearer <token>`.
- Список лотов: `GET /telegram` с теми же параметрами, что у сайта:
  `country[]`, `min_contacts`, `spam`, `order_by`, `page`, `pmin`, `pmax`.
- Ответ: `items` (лоты), `totalItems`, `perPage`, `hasNextPage`.
  У лота есть `item_id`, `title`, `price`, `price_currency`, `published_date`,
  `item_origin` и поля `telegram_*`.
- Лимит для поиска по категориям: 120 запросов в минуту, при превышении
  API отвечает `429`. Монитор делает один запрос за проверку, при `429`
  ждёт `Retry-After`. Интервал 60 секунд с большим запасом.

Чтобы увидеть, какие именно поля приходят по вашему фильтру:

```bash
python monitor.py --dump
```

## Файлы

- `monitor.py` — сам монитор и бот (`--once` для одной проверки, `--test` для
  тестового сообщения, `--dump` чтобы напечатать сырой ответ API).
- `web_source.py` — разбор HTML-страницы каталога для режима `web`.
- `state.json` — отправленные лоты и подписчики, создаётся автоматически.
